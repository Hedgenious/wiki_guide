Формат цитирования по ГОСТ

Правила оформления источников и библиографических ссылок для Википедии

🎯 Цель этого руководства

Это руководство научит вас правильно оформлять источники и цитаты в Википедии согласно российским стандартам ГОСТ и требованиям энциклопедии.

📚 Основные принципы цитирования

Зачем нужны источники

  • Подтверждают достоверность информации
  • Позволяют читателям проверить факты
  • Показывают авторитетность статьи
  • Соответствуют принципу проверяемости

Типы источников

📖 Первичные источники

  • Научные статьи
  • Официальные документы
  • Монографии
  • Диссертации

📰 Вторичные источники

  • Энциклопедии
  • Учебники
  • Обзорные статьи
  • Справочники

📝 Форматы цитирования

Книги

Формат:

Автор. Название книги. — Место издания: Издательство, год. — С. страницы.

Пример:

Иванов И.И. История России. — М.: Просвещение, 2020. — С. 45-67.

Статьи в журналах

Формат:

Автор. Название статьи // Название журнала. — Год. — № номер. — С. страницы.

Пример:

Петров П.П. Современные технологии // Наука и жизнь. — 2023. — № 5. — С. 12-18.

Интернет-источники

Формат:

Название сайта. URL: ссылка (дата обращения: дата).

Пример:

Официальный сайт РАН. URL: https://www.ras.ru (дата обращения: 15.03.2024).
