Подбор источников

Руководство по поиску и верификации надёжных источников для Википедии

🎯 Цель этого руководства

Это руководство научит вас находить и проверять надёжные источники информации для статей Википедии.

Пример успешного поиска в Википедии - можно найти существующие статьи для улучшения

📄 Авторство и лицензии

При работе с изображениями важно правильно указывать авторство:

Google Images показывает источник изображений - Wikimedia Commons с указанием авторства

Пример цитирования из Википедии в результатах поиска Google - показывает авторитетность источников

Обязательные элементы

  • Автор: кто создал изображение
  • Лицензия: CC BY, CC BY-SA, Public Domain
  • Источник: откуда взято изображение
  • Дата: когда было создано
Помните: Лицензия Википедии требует указания ссылки на автора. Это видно в результатах поиска Google.

✅ Критерии надёжности

Авторитетность

  • Признанные эксперты в области
  • Учёные степени и звания
  • Работа в авторитетных учреждениях
  • Цитируемость в научной литературе

Объективность

  • Отсутствие предвзятости
  • Нейтральная точка зрения
  • Проверяемые факты
  • Отсутствие рекламы

🔍 Где искать источники

Пример поиска по "DADA School" в Википедии - показывает, как найти связанные статьи и источники

Научные базы данных

  • eLIBRARY.RU - российская научная электронная библиотека
  • Google Scholar - поиск научных публикаций
  • JSTOR - архив научных журналов
  • PubMed - медицинские исследования

Официальные источники

  • Сайты государственных органов
  • Официальные статистические данные
  • Правительственные документы
  • Международные организации

⚠️ Что НЕ использовать

❌ Ненадёжные источники

  • Блоги и личные сайты
  • Социальные сети
  • Википедия (циклические ссылки)
  • Новостные сайты без редакции

🔍 Проверка источников

Критерии проверки

  1. Автор - кто написал?
  2. Дата - когда опубликовано?
  3. Издатель - кто издал?
  4. Цель - зачем создано?
  5. Актуальность - не устарело ли?

Красные флаги

  • Отсутствие информации об авторе
  • Неточные или отсутствующие даты
  • Орфографические ошибки
  • Эмоциональная окраска
  • Отсутствие ссылок на другие источники
